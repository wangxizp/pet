# PawPal 宠伴 · 养宠成长记录与社区

> 一站式记录宠物成长、管理健康档案、匹配同城宠友的轻量应用。

## 功能一览

| 模块 | 能力 |
| --- | --- |
| 🐕 宠物档案 | 多宠管理：头像 / 品种 / 性别 / 生日 / 体重，自动计算年龄，记录数统计 |
| 💉 健康记录 | 体重趋势曲线（SVG 折线图）、疫苗接种 / 驱虫打卡、下次时间到期提醒（红 / 橙双色预警） |
| 🗓️ 成长时间线 | 体重 / 疫苗 / 驱虫 / 心情日记自动编排为纵向成长轴 |
| 💬 宠友社区 | 按城市筛选附近宠友（17 位模拟宠友 / 11 城市）、动态广场发帖与点赞 |

## 产品设计思路

- **目标用户**：养宠年轻人，移动端优先体验。
- **核心闭环**：添加宠物 → 记录健康数据 → 自动生成成长时间线 → 在社区分享 / 求助。
- **痛点切入**：
  - 健康数据零散（疫苗本、体重随手记）→ 统一档案 + 到期主动提醒；
  - 成长回忆难以沉淀 → 时间线自动编排，无需手动整理；
  - 缺少同城宠友交流 → 按城市匹配 + 广场动态。

## 技术方案

- **纯前端单页应用**：原生 HTML / CSS / JavaScript，单文件、零外部依赖，打开即用。
- **数据存储**：浏览器 `localStorage`，刷新不丢失；首次打开自动注入演示数据（2 只宠物、17 条记录、5 条动态），可一键重置。
- **部署**：GitHub Pages（域名固定、公开访问）。

## 本地运行

直接双击 `index.html` 即可，或：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（如 `pawpal`）。
2. 将 `index.html`、`README.md` 上传到仓库根目录。
3. 仓库 **Settings → Pages → Build and deployment**，Source 选择 `Deploy from a branch`，分支选 `main` / `(root)`，保存。
4. 1-2 分钟后访问 `https://<你的用户名>.github.io/pawpal/`。
